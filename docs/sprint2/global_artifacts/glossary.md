# AISafe – Domain Model Glossary
**Domain-Driven Design **

| Term                        | Definition                                                                                                                                                                                                   |
|-----------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Admin**                   | Person who administers the system. Manages system users, backoffice operators, and security clearances.                                                                                                      |
| **AerodynamicCoefficients** | Holds the zero-lift drag coefficient and lift coefficient of an AircraftModel. Used in simulation to compute lift and drag forces.                                                                           |
| **AirControlArea**          | A geographic region with a unique code and boundary. Defines a minimum fuel requirement for flights landing within it.                                                                                       |
| **Aircraft**                | A physical aircraft of a specific model, belonging to an AirTransportCompany. Identified by its unique registration and fitted with a certified engine configuration.                                        |
| **AircraftModel**           | Defines physical and performance characteristics used in simulation, including weight limits, wing geometry, and certified engine configurations.                                                            |
| **AircraftType**            | Classification of an aircraft model based on its operational purpose (passenger, cargo, or mixed).                                                                                                           |
| **AircraftRegistration**    | Unique registration number (tail number) that identifies an Aircraft worldwide.                                                                                                                              |
| **Airport**                 | Installation with unique IATA and ICAO codes. Always associated with one AirControlArea and defined by its coordinates(longitude,altitude,latidude)                                                          |
| **AirportIATACode**         | 3-letter code that uniquely identifies an Airport worldwide.                                                                                                                                                 |
| **AirportICAOCode**         | 4-letter code that uniquely identifies an Airport worldwide.                                                                                                                                                 |
| **AirTransportCompany**     | A company that operates aircrafts and flights. Identified by unique airline codes and employs collaborators with specific positions(ATCC and Pilots).                                                        |
| **AISafe**                  | Startup developing a prototype flight control system for managing aircraft, flight management, and weather services.                                                                                         |
| **AreaCode**                | Unique code that identifies an AirControlArea within the system.                                                                                                                                             |
| **CabinConfiguration**      | Description of the number of seats per cabin class for a physical Aircraft. Total seats cannot exceed the model's capacity.                                                                                  |
| **CollaboratorPosition**    | The specific function of a company employee (e.g., ATCC or PILOT).                                                                                                                                           |
| **CollaboratorStatus**      | Operational status of a company employee, indicating if they are currently active or inactive.                                                                                                               |
| **CompanyCollaborator**     | An airline employee with system access. Must hold a valid security clearance and belongs to exactly one company.                                                                                             |
| **CompanyIATACode**         | 2-letter code that uniquely identifies an AirTransportCompany worldwide.                                                                                                                                     |
| **CompanyICAOCode**         | 2–3 letter code that uniquely identifies an AirTransportCompany worldwide.                                                                                                                                   |
| **CompanyStatus**           | Status of an airline in the system, determining if it can currently operate flights.                                                                                                                         |
| **CountryCode**             | The country of origin of a Manufacturer.                                                                                                                                                                     |
| **DeactivationDate**        | The date from which a Route is no longer operational. Prevents new flight plans while preserving existing history.                                                                                           |
| **EngineConfiguration**     | The certification of a specific engine model for use on a specific aircraft model. A model must retain at least one certified configuration.                                                                 |
| **EngineModel**             | Specification of an engine type. Defined by its name, fuel type, efficiency (TSFC), and thrust profile.                                                                                                      |
| **FCO**                     | Flight Control Operator. A collaborator at a control entity who validates flight plans and simulates air traffic control.                                                                                    |
| **Flight**                  | A specific occurrence of a Route with a stable code and schedule. It moves through a lifecycle from planning to execution.                                                                                   |
| **FlightDesignator**        | Unique flight identifier following international standards, composed of the airline code (2 letters), a numeric flight number (up to 4 digits), and an optional one-letter suffix (e.g., XX1234 or XX1234A). |
| **FlightLeg**               | A non-stop segment between two airports within a FlightPlan. A FlightPlan with a layover has multiple Legs. Each Leg has its own fuel, segment, and time information.                                        |                                      
| **FlightLoad**              | The combined weight of passengers and cargo carried by a flight, used for physics calculations.                                                                                                              |
| **FlightPlan**              | The specific operational setup for a flight, including aircraft, pilot, load, and fuel. Must be validated through simulation.                                                                                |
| **FlightPlanStatus**        | Lifecycle of a plan, moving from draft to submitted, and finally to approved or rejected.                                                                                                                    |
| **FlightSchedule**          | The specific departure and arrival times assigned to a flight plan.                                                                                                                                          |
| **FlightSimulationReport**  | The recorded result of a simulation run, confirming if a flight plan is technically viable.                                                                                                                  |
| **FlightStatus**            | Operational lifecycle of a flight: planning, pending, executed, or cancelled.                                                                                                                                |
| **FlightType**              | Classification of a flight or plan as either a regular or charter service.                                                                                                                                   |
| **FuelLoad**                | Total fuel quantity loaded for a flight. Must satisfy the minimum fuel requirements of the destination area.                                                                                                 |
| **GeographicBoundary**      | The polygon coordinates that define the physical spatial extent of an AirControlArea.                                                                                                                        |
| **GeoCoordinates**          | Geographic position representing latitude, longitude, and altitude.                                                                                                                                          |
| **Manufacturer**            | Entity that manufactures aircraft or engines. Also known as a Maker.                                                                                                                                         |
| **MinFuelRequirement**      | The minimum fuel quantity that must remain on board when an aircraft reaches its destination.                                                                                                                |
| **Motorization**            | Type of propulsion system of an aircraft model (e.g., turbofan, electric propeller).                                                                                                                         |
| **MTOW**                    | Maximum Take-Off Weight. The maximum permissible weight of an aircraft at take-off.                                                                                                                          |
| **MZFW**                    | Maximum Zero Fuel Weight. The maximum permissible weight of an aircraft without its usable fuel.                                                                                                             |
| **Node**                    | Junction point between two or more segments of airspace.                                                                                                                                                     |
| **NumberOfFlightCrew**      | Number of crew members required to operate a specific aircraft.                                                                                                                                              |
| **ObservationPeriod**       | The time window during which a specific set of weather data is valid.                                                                                                                                        |
| **OperationalStatus**       | Status of an aircraft, indicating if it is active or decommissioned.                                                                                                                                         |
| **PerformanceSpec**         | Group of performance limits including cruise speed, maximum range, and service ceiling.                                                                                                                      |
| **Pilot**                   | An airline employee certified to fly specific aircraft models. Must maintain active certifications to be assigned to flights.                                                                                |
| **PilotCertification**      | Authorization for a pilot to operate a specific aircraft model, valid for a specific period.                                                                                                                 |
| **PlannedSchedule**         | The specific planned departure and arrival times for a flight occurrence.                                                                                                                                    |
| **Pressure**                | Atmospheric pressure used to compute air density and engine thrust during simulation.                                                                                                                        |
| **Route**                   | A recurring connection between two airports. It is deactivated rather than deleted to maintain historical integrity.                                                                                         |
| **SecurityClearance**       | Authorization required for system access, requiring renewal every 5 years based on skill assessments.                                                                                                        |
| **Segment**                 | A linear path connecting two points in airspace. It has start and end coordinates, allowed altitudes with widths per slot, and wind data.                                                                    |
| **SegmentAltitudes**        | Minimum and maximum altitudes of a segment.                                                                                                                                                                  |
| **SegmentWindData**         | Wind data for a segment obtained from an observation period.                                                                                                                                                 |
| **Temperature**             | Air temperature used to compute air density for lift and drag calculations.                                                                                                                                  |
| **ThrustProfile**           | Specification of engine thrust at different speeds and altitudes.                                                                                                                                            |
| **TSFC**                    | Thrust Specific Fuel Consumption. Measure of the fuel efficiency of an engine design.                                                                                                                        |
| **WeatherData**             | Meteorological observations for an area, including wind data, temperature, pressure, and humidity.                                                                                                           |
| **WeatherPerson**           | System user responsible to obtain and register weather data.                                                                                                                                                 |
| **WeightSpecification**     | Group of weight limits for an aircraft model, including empty weight, MTOW, and MZFW.                                                                                                                        |
| **WindData**                | Record of wind direction and speed used in flight simulation.                                                                                                                                                |
| **WingGeometry**            | Physical measurements of an aircraft's wing used for aerodynamic calculations.                                                                                                                               |
